# Sprite assets

Put the 9 named PNG sprite sheets in this folder:

```text
cowboy_idle.png
cowboy_walk.png
cowboy_shoot.png
cowboy_hurt.png
cowboy_die.png
zombie_idle.png
zombie_walk.png
zombie_hurt.png
zombie_die.png
```

The game automatically loads them from `assets/sprites/`.

The in-game SPRITES panel is kept as a backup uploader for testing.
